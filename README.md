# 防災アプリ

Flask 製の防災アプリです。ローカルでは次のコマンドで起動できます。

```sh
python app.py
```

## 職員ログイン

職員向けの指示ボードと避難所登録にはパスワード `123` でログインします。これは開発・デモ用途の弱い固定パスワードであり、本番環境での使用は推奨しません。公開環境では必ず強固な認証へ置き換えてください。

Flask セッション署名用には、`FLASK_SECRET_KEY` に十分ランダムな値を設定し、複数プロセス／再起動後も同じ値を使ってください。秘密鍵は `python -c "import secrets; print(secrets.token_hex(32))"` などで生成し、秘密情報管理機能に保存してください。

## 対象地域とデータ

気象庁の対象地域名、都道府県コード、市区町村コード、および初期地図中心は `app.py` の `REGION` にまとめています。既定値は青森市です。地域を変更する場合は、気象庁の公開コードに基づいて一緒に更新してください。

避難所データは `bousai_app/data/shelters.json` に保存します。既存施設に位置情報や設備・収容情報を補う場合は、確認済みの値だけを任意フィールドとして登録してください。利用可能なフィールドは `district`、`disaster_types`、`pet_friendly`、`barrier_free`、`wheelchair_toilet`、`welfare_space`、`latitude`、`longitude`、`address`、`open_status`、`capacity`、`evacuee_count` です。未登録値は推測で補完されず、設備状態や空き状況には「情報なし」と表示されます。空き状況は収容人数の90%以上を「ほぼ満員」、収容人数以上を「満員」として表示します。

指示は職員ボードから登録され、`bousai_app/data/instructions.json` に保存されます。ローカルの永続ファイルシステムでは、プロセス再起動後もデータを読み込みます。`vercel.json` のようなサーバーレス環境では、実行ファイルシステムの書き込みを永続ストレージとして扱えません。継続的な本番運用には、永続データベースまたは永続ボリュームへの移行が必要です。
